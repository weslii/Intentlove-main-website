# Intentlove Admin Dashboard

A modern, beautiful, and mobile-responsive admin dashboard for the Intentlove ecommerce platform.

## 🚀 Features

### Core Dashboard
- **Real-time Analytics**: Sales metrics, revenue tracking, and performance indicators
- **Order Management**: Complete order lifecycle management with status tracking
- **Product Management**: Inventory control and product catalog management
- **Customer Management**: Customer database and relationship management
- **Mobile Responsive**: Optimized for all device sizes

### Modern UI/UX
- **Beautiful Design**: Clean, modern interface with consistent design system
- **Dark/Light Mode**: Built-in theme support
- **Smooth Animations**: Elegant transitions and micro-interactions
- **Accessibility**: WCAG compliant components

### Technical Features
- **TypeScript**: Full type safety and better developer experience
- **Modular Architecture**: Reusable components and clean code structure
- **Performance Optimized**: Fast loading and smooth interactions
- **SEO Ready**: Optimized for search engines

## 🛠️ Tech Stack

- **Frontend**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI + Custom Components
- **Routing**: React Router DOM
- **Charts**: Recharts (for future analytics)
- **Icons**: Lucide React
- **State Management**: React Hooks + Context (expandable)

## 📁 Project Structure

```
src/
├── components/          # Reusable UI components
│   ├── ui/            # Base UI components (Button, Card, etc.)
│   ├── Sidebar.tsx    # Navigation sidebar
│   ├── Header.tsx     # Top header bar
│   └── StatsCard.tsx  # Statistics display component
├── pages/             # Page components
│   └── Dashboard.tsx  # Main dashboard page
├── lib/               # Utility functions and helpers
│   └── utils.ts       # Common utilities
└── App.tsx           # Main app component with routing
```

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd admin-dashboard
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   Navigate to `http://localhost:5173`
